# 12 · Capstone 小助手

## 目标

把前面的能力收进一个可运行助手：

- 模拟天气 + 模拟搜索工具
- `MemorySaver` 跨轮记忆
- 发送消息前 `interrupt` 人工确认

这是本课程的验收作品：能讲清图怎么走、记忆存在哪、为什么要 HITL。

## 建议自测

1. 先问天气，再在同一 `thread_id` 问「刚才说的是哪个城市」
2. 要求「把摘要发给 ops@example.com」，应暂停而不是直接发送
3. `resume=yes` 后才真正发送

## 本课文件

先跑 `demo.py`（脚本化，不需要交互输入），再按 `exercise.md` 加一个工具。
